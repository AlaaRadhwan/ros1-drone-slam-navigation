# Evidence files

| File | What it is |
|---|---|
| `my_map_cropped.png`, `map2_cropped.png` | **Portfolio visualization images.** Cropped, down-sampled PNG renderings of two saved gmapping occupancy grids (`my_map`: 29 Jul 2024; `map2`: 3 Aug 2024), made for this repository from the original 4000x4000 PGM files. Unknown space is grey, free space white, occupied black. |
| `my_map.yaml`, `map2.yaml` | The historical `map_server` metadata (resolution 0.05 m/pixel, origin -100, -100, thresholds). The `image:` fields point to `./my_map.pgm` / `./map2.pgm`, which are **not included** (the 16 MB originals are excluded). `my_map.yaml`'s original absolute home path was replaced by a relative one. |
| `frames.png` | `view_frames` snapshot, 26 Jul 2024 (earlier): `/tf_broadcaster` publishes `odom -> base_link` and the Hokuyo frames; `/slam_gmapping` publishes `map -> odom`. |
| `frames.gv` | `view_frames` Graphviz dump, 29 Jul 2024 (later): `/mavros` publishes `odom -> base_link` (plus NED helper frames); static publishers provide the Hokuyo frames; `/slam_gmapping` publishes `map -> odom`. |

**Do not load the PNGs with `map_server`.** The cropped PNGs have different dimensions and origin than the YAML describes. Loadable map images would have to be regenerated by re-running SLAM and `map_saver`.

No quantitative evaluation, rosbag or log from the demonstration survives.
